# microservice chart

The platform's single chart for every service. Platform-team owned; versioned with the
kro RGDs in `platform/bootstrap/rgds`. Service repos provide only
`deploy/values-<env>.yaml`. The deploy pipeline injects `global` and the image tag.

- Contract: [`values.schema.json`](values.schema.json) (strict). Defaults: [`values.yaml`](values.yaml).
- Validate a values file: `python platform/workflows/scripts/platform_deploy.py validate --values <file>`.
- Agents: see [`CLAUDE.md`](CLAUDE.md) and the `new-service` skill's
  [values cookbook](../../../.claude/skills/new-service/references/values-cookbook.md).

## What it renders

| Kind | Purpose |
|---|---|
| `Deployment` (replicas 0) | Pod template for the Rollout (`workloadRef`) |
| `Rollout` + `AnalysisTemplate` | Canary steps gated by Prometheus analysis; automatic abort |
| `Service`, `ServiceAccount` (IRSA), `HorizontalPodAutoscaler`, `PodDisruptionBudget` | Standard workload plumbing |
| `Ingress` (ALB) / `Service` (NLB) | Optional exposure via the AWS Load Balancer Controller |
| `PlatformQueue` / `PlatformTopic` / `PlatformBucket` / `PlatformTable` / `PlatformDatabase` | One per `aws.*` entry (sync wave -2): resource + scoped IAM policy |
| `PlatformWorkloadIdentity` | The IRSA role (sync wave -1): trust pinned to the ServiceAccount, permissions boundary, sibling policies attached |

### AWS resources

| Key | Fields (`*` required) |
|---|---|
| `aws.sqs[]` | `name`*: string, `access`*: `consume` \| `publish` \| `consumepublish`, `fifo`: boolean, `visibilityTimeoutSeconds`: integer, `messageRetentionSeconds`: integer |
| `aws.sns[]` | `name`*: string, `access`*: `publish`, `fifo`: boolean |
| `aws.s3[]` | `name`*: string, `access`*: `read` \| `readwrite`, `versioning`: boolean, `deletionPolicy`: `retain` \| `delete` |
| `aws.dynamodb[]` | `name`*: string, `access`*: `read` \| `readwrite`, `partitionKey`*: object, `sortKey`: object, `deletionPolicy`: `retain` \| `delete` |
| `aws.rds[]` | `name`*: string, `engine`*: `postgres` \| `mysql`, `engineVersion`: string, `instanceClass`: string, `allocatedStorageGB`: integer, `access`*: `connect`, `deletionPolicy`: `retain` \| `delete` |
<!-- values-reference:end -->

Access levels map to fixed IAM action sets:

| Resource | Access | Actions |
|---|---|---|
| SQS | `consume` | ReceiveMessage, DeleteMessage, ChangeMessageVisibility, GetQueueAttributes, GetQueueUrl |
| SQS | `publish` | SendMessage, GetQueueAttributes, GetQueueUrl |
| SQS | `consumepublish` | both of the above |
| SNS | `publish` | Publish, GetTopicAttributes |
| S3 | `read` / `readwrite` | ListBucket, GetBucketLocation, GetObject (+ PutObject, DeleteObject) |
| DynamoDB | `read` / `readwrite` | GetItem, BatchGetItem, Query, Scan, DescribeTable (+ PutItem, UpdateItem, DeleteItem, BatchWriteItem) on the table and its indexes |
| RDS | `connect` | rds-db:connect as the DB user named after the service |

| Variable | When |
|---|---|
| `PLATFORM_SERVICE`, `PLATFORM_ENVIRONMENT`, `PLATFORM_VERSION` | always |
